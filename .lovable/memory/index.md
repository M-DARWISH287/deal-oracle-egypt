# Project Memory

## Core
BestDeal.ai — AI price comparison for Egyptian electronics. Light theme (purple #8B5CF6 primary). RTL Arabic default, bilingual AR/EN. 13 stores in 3 tiers. Auth with email + Google OAuth. Credit system (100 default, atomic reserve/settle via DB functions).

## Memories
- [Design system](mem://design/theme) — Dark slate bg, neon purple/blue accents, glow borders, shimmer skeletons
- [Product requirements](mem://features/prd) — Tiered scraping, deep-linking, copy link fallback, store logos, RTL layout
- [Scraping debug](mem://features/scraping-debug) — SerpApi/Firecrawl root causes and fixes
- [Architecture](mem://features/architecture) — 13-store adapter, 3-tier cascade, stateless Supabase, 15s timeout, credit lifecycle
